# Folder Structure — Clay & Co.

This document describes the repository layout with a one-line description of the purpose of each directory and file based on the active codebase.

```
interactive-3d-tile-experience/
├── .env                              # Environment variable configuration (database URL and secrets)
├── .env.example                      # Template for required environment variables
├── .gitignore                        # Git exclusion rules for node_modules, build artifacts, and env files
├── AGENTS.md                         # Next.js agent conventions and Turbopack rules
├── CLAUDE.md                         # Command-line quick reference pointer
├── README.md                         # Comprehensive project readme, quick start, and script reference
├── drizzle.config.ts                 # Drizzle Kit configuration defining schema paths and DB credentials
├── eslint.config.mjs                 # Flat ESLint configuration with Next.js rules
├── next.config.ts                    # Next.js configuration options (Turbopack, image domains, headers)
├── next-env.d.ts                     # TypeScript declarations auto-generated by Next.js
├── package.json                      # Project dependencies, scripts, engines, and metadata
├── package-lock.json                 # Pinned dependency lockfile
├── postcss.config.mjs                # PostCSS configuration integrating @tailwindcss/postcss
├── tsconfig.json                     # TypeScript compiler options and path aliases (@/* -> ./src/*)
│
├── docs/                             # Project documentation directory
│   ├── API_DESIGN.md                 # REST API endpoints, request schemas, and response formats
│   ├── CURRENT_STATUS.md             # Project status, complete features, partial items, and roadmap
│   ├── DATABASE_DESIGN.md            # Schema tables, fields, constraints, and Mermaid ER diagram
│   ├── DATABASE_SETUP.md             # Detailed walkthrough for setting up and troubleshooting MySQL
│   ├── FOLDER_STRUCTURE.md           # Repository file tree with one-line descriptions
│   ├── PROGRESS.md                   # Industry-readiness phase roadmap and verification evidence
│   ├── PROJECT_OVERVIEW.md           # Problem statement, technology stack, and target audience
│   ├── QUICK_START.md                # Quick start instructions for initializing and running the project
│   ├── REQUIREMENTS.md               # Must-have and partially implemented feature specifications
│   ├── SYSTEM_DESIGN.md              # Architectural tiers, data pipelines, and Mermaid diagrams
│   └── reference/                    # Reference documentation and design inspiration assets
│
├── drizzle/                          # SQL migrations generated by Drizzle Kit
│   ├── 0000_fearless_abomination.sql # Initial database schema migration
│   ├── 0001_nosy_taskmaster.sql      # Schema additions and constraint updates
│   ├── 0002_dazzling_omega_red.sql   # Orders lifecycle, events, payment tracking, idempotency
│   └── meta/                         # Drizzle Kit migration metadata and snapshots
│
├── public/                           # Static assets served directly at the root URL
│   ├── draco/                        # Draco WebGL geometry decompression worker files
│   ├── images/                       # Static site preview images and fallback photography
│   │   ├── hero-fallback.jpg         # High-resolution hero fallback image for low-tier devices

│   └── models/                       # 3D assets used by Three.js and model-viewer
│       └── furniture/                # Binary glTF (.glb) 3D furniture models
│           ├── armchair.glb          # 3D mesh model for armchair products
│           ├── bookshelf.glb         # 3D mesh model for bookshelf products
│           ├── coffee-table.glb      # 3D mesh model for coffee table products
│           ├── floor-lamp.glb        # 3D mesh model for floor lamp products
│           └── manifest.json         # Manifest describing available 3D furniture model files
│
├── scripts/                          # Build, maintenance, and utility scripts
│   ├── backup-db.mjs                 # Database backup snapshot script
│   ├── cleanup-carts.mjs             # Cron maintenance script purging expired cart sessions
│   ├── expire-pending-orders.mjs     # Cron script cancelling unpaid pending orders > 60 minutes
│   ├── generate-furniture-models.mjs # Procedural generator script exporting GLB furniture assets
│   ├── generate-pbr-maps.mjs         # Node.js canvas script generating PBR normal and roughness maps
│   ├── hash-admin-password.mjs       # Utility computing scrypt hashes for admin credentials
│   ├── migrate-db.mjs                # Database schema migration runner
│   ├── setup-test-db.mjs             # Test database isolation and migration runner
│   └── verify-database.mjs           # Automated 5-step test script validating DB, tables, seed, and cart
│
└── src/                              # Application source code
    ├── proxy.ts                      # Edge-compatible security guard and rate limiting
    │
    ├── app/                          # Next.js App Router pages, layouts, and route handlers
    │   ├── globals.css               # Global CSS stylesheet, font imports, and theme tokens
    │   ├── layout.tsx                # Simplified root HTML shell layout
    │   ├── (admin)/                  # Route group for back-office admin
    │   │   └── admin/
    │   │       ├── layout.tsx        # Admin top navigation bar layout
    │   │       ├── page.tsx          # Protected Admin dashboard displaying live inventory
    │   │       ├── AdminLogoutButton.tsx # Client component handling admin logout request
    │   │       └── login/
    │   │           └── page.tsx      # Administrator password login screen
    │   │
    │   ├── api/                      # Backend REST API Route Handlers
    │   │   ├── admin/

    │   │   │   └── logout/route.ts   # POST: Admin session cookie revocation
    │   │   ├── cart/

    │   │   ├── health/

    │   │   └── products/

    │   │       └── [slug]/route.ts   # GET: Fetch single product details and variants by slug
    │   │
    │   ├── (store)/                  # Route group for customer shopping experience
    │   │   ├── layout.tsx            # Consumer layout with Navbar and Footer
    │   │   ├── page.tsx              # Homepage featuring 3D Hero tile wall
    │   │   ├── cart/
```
